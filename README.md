Friends Wordle

Why this project exists

This project is a personal Wordle-style game built specifically for me and my friends. The goal is not just to clone Wordle, but to learn by building using GitHub.

I’m using this project to practice:
	•	Writing clean, understandable JavaScript
	•	Structuring small projects like a real engineer
	•	Thinking in terms of state, logic, and edge cases
	•	Shipping features incrementally instead of chasing perfection

By the end of this project, I want a polished, fun game that reflects my friend group’s culture and inside jokes.

Learning goals
	•	Strengthen fundamentals in HTML, CSS, and JavaScript
	•	Practice breaking problems into small, solvable pieces
	•	Build the habit of making meaningful commits every day
	•	Learn how small systems (like games) are designed end-to-end

What makes this Wordle different
	•	Custom word list tailored to my friends
	•	Custom win/loss messages
	•	Private link (not meant for the public)
	•	Focus on learning and experimentation over perfection

Project roadmap (high level)
	•	Build a playable Wordle clone from scratch
	•	Implement correct scoring logic (green, yellow, gray)
	•	Add daily word functionality
	•	Track stats locally
	•	Customize UI and themes
	•	Refactor and test core logic

Tech stack
	•	HTML
	•	CSS
	•	JavaScript (no frameworks initially)
	•	GitHub Pages for deployment

This repository is part of my goal to make at least one GitHub commit every day in 2026. Each commit represents a small but intentional step forward.

Progress > perfection.
